# Unified Docker Deployment Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Consolidate Ponta Remote into a single all-in-one Docker image (`ngotuananh2101/ponter`) containing the Node.js backend server (`@ponter/server`), compiled web frontend (`@ponter/web`), and an Nginx reverse proxy managed by Supervisord, exposing exactly one port (default `80`) with runtime frontend configuration, driven by two compose files (`docker-compose.yml` and `docker-compose.coturn.yml`), while retiring Cloudflare Pages/Tunnels/Caddy and strictly retaining Cloudflare TURN server code.

**Architecture:** A multi-stage Docker build (`node:24-alpine`) compiles `@ponter/server` and `@ponter/web`. In the runner stage, Supervisord supervises two processes: Nginx listening on port 80 (serving the SPA, injecting security headers, serving runtime `/config.js`, and reverse-proxying `/api/` and WebSockets) and `@ponter/server` listening on internal loopback `127.0.0.1:8787` as unprivileged user `node`. The web frontend dynamically resolves its API endpoint via `window.__PONTER_CONFIG__.apiUrl` generated at boot time by `entrypoint.sh`, defaulting to same-origin. Exactly two compose files replace the legacy 4-compose matrix.

**Tech Stack:** Docker, Docker Compose, Nginx (Alpine), Supervisord (Python/Alpine), Node.js 24, pnpm, Vue 3, Vite, Hono, Coturn.

**Spec:** `docs/superpowers/specs/2026-10-14-unified-docker-deployment-design.md`

## Global Constraints

- Default published HTTP port is 80, overridable via `PONTER_HTTP_PORT`.
- Exactly two Docker Compose files: `docker/docker-compose.yml` and `docker/docker-compose.coturn.yml`.
- Unified image published to Docker Hub repository `ngotuananh2101/ponter`.
- Process supervision inside container uses Alpine `supervisor` (supervisord), NOT s6-overlay.
- Backend server runs internally on `127.0.0.1:8787` as unprivileged user `node` via `su-exec node`.
- Nginx runs in foreground on port 80 as root, proxying `/api/` and WebSocket upgrades.
- Web frontend resolves API endpoint at runtime via `window.__PONTER_CONFIG__.apiUrl` generated by `docker/entrypoint.sh` into `/usr/share/nginx/html/config.js`.
- Cloudflare TURN relay provider (`TURN_PROVIDER=cloudflare`) in `apps/server/src/utils/ice.ts` and `test/ice-provider.test.ts` MUST be strictly preserved.
- Cloudflare Pages (`deploy.yml`, `wrangler.toml`, devDep `wrangler`, root `deploy:web`), Cloudflare Tunnels (`docker/cloudflared/`), Caddy (`docker/Caddyfile`), and legacy compose files (`docker-compose.{local,prod,nginx,tunnel}.yml`, `nginx.conf.example`) are deleted.
- No commit trailers (`Co-authored-by` etc.).
- Zero Vietnamese characters in technical documentation or code.

## Review Focus

1. **Runtime config fallback chain:** When `window.__PONTER_CONFIG__.apiUrl` is undefined, empty, or whitespace-only, `getApiBaseUrl()` must cleanly fall back to `VITE_API_URL`, then `window.location.origin`, then `'http://localhost:8787'`.
2. **WebSocket signaling proxy:** Nginx must pass WebSocket upgrade headers (`Upgrade $http_upgrade`, `Connection $connection_upgrade`) with `proxy_read_timeout 86400s` and `proxy_buffering off` for both `/api/ws/agent` and `/api/ws/browser`.
3. **Data directory permissions:** When host bind-mounts `./data` to `/app/data` with root ownership, `docker/entrypoint.sh` must `chown -R node:node` before launching Supervisord so SQLite does not fail with `SQLITE_CANTOPEN`.
4. **Single port exposure:** The container publishes only port 80. The internal backend on `127.0.0.1:8787` must never be exposed directly to the host network.
5. **Coturn standalone execution:** `docker/docker-compose.coturn.yml` must run cleanly as a standalone compose file (`docker compose -f docker-compose.coturn.yml up -d`) without requiring flags from `docker-compose.yml`.

Create `apps/web/src/config.ts`:

```typescript
declare global {
  interface Window {
    __PONTER_CONFIG__?: {
      apiUrl?: string;
    };
  }
}

/**
 * Resolve the API base URL following runtime precedence:
 * 1. Runtime injection via window.__PONTER_CONFIG__.apiUrl (if non-empty)
 * 2. Build-time Vite environment variable VITE_API_URL (if provided)
 * 3. Browser origin window.location.origin (default for same-origin all-in-one container)
 * 4. Fallback 'http://localhost:8787' (for node/SSR environments without window.location)
 */
export function getApiBaseUrl(): string {
  if (typeof window !== 'undefined') {
    const runtimeApiUrl = window.__PONTER_CONFIG__?.apiUrl?.trim();
    if (runtimeApiUrl && runtimeApiUrl.length > 0) {
      return runtimeApiUrl;
    }
  }

  const buildApiUrl = import.meta.env.VITE_API_URL?.trim();
  if (buildApiUrl && buildApiUrl.length > 0) {
    return buildApiUrl;
  }

  if (typeof window !== 'undefined' && window.location?.origin && window.location.origin !== 'null') {
    return window.location.origin;
  }

  return 'http://localhost:8787';
}
```

```nginx
# Connection upgrade map for WebSocket support
map $http_upgrade $connection_upgrade {
    default upgrade;
    ''      close;
}

server {
    listen 80 default_server;
    listen [::]:80 default_server;
    server_name _;

    root /usr/share/nginx/html;
    index index.html;

    client_max_body_size 50M;

    # Security headers (ported from apps/web/public/_headers)
    add_header Content-Security-Policy "default-src 'self'; script-src 'self'; style-src 'self' 'unsafe-inline'; img-src 'self' data: blob:; connect-src 'self' https: wss:; media-src 'self' blob:; font-src 'self'; object-src 'none'; base-uri 'self'; form-action 'self'; frame-ancestors 'none'" always;
    add_header X-Content-Type-Options "nosniff" always;
    add_header Referrer-Policy "strict-origin-when-cross-origin" always;
    add_header Permissions-Policy "camera=(), microphone=(), geolocation=()" always;

    # Runtime frontend configuration script (generated by entrypoint)
    location = /config.js {
        add_header Cache-Control "no-store, no-cache, must-revalidate" always;
        add_header Content-Type "application/javascript" always;
    }

    # Direct health-check proxy for container readiness probes
    location = /health {
        proxy_pass http://127.0.0.1:8787/health;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    # API endpoints and WebSocket signaling proxy
    location /api/ {
        proxy_pass http://127.0.0.1:8787;
        proxy_http_version 1.1;

        # WebSocket headers (critical for /api/ws/agent and /api/ws/browser)
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection $connection_upgrade;

        # Standard reverse-proxy headers
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;

        # Keep alive settings for long-lived WebSockets
        proxy_read_timeout 86400s;
        proxy_send_timeout 86400s;
        proxy_connect_timeout 60s;

        # Disable buffering for real-time WebRTC signaling
        proxy_buffering off;
    }

    # SPA history mode fallback
    location / {
        try_files $uri $uri/ /index.html;
    }
}
```

```dockerfile
###############################################################################

ENV PNPM_HOME="/pnpm"

# Stage 2: builder — compile @ponter/server and @ponter/web
###############################################################################

# Copy package manifests and workspace lockfiles
COPY pnpm-lock.yaml pnpm-workspace.yaml package.json tsconfig.base.json ./

# Build backend server
RUN pnpm --filter @ponter/server build

# Build frontend SPA with browser WebSocket signaling flag enabled
ENV VITE_BROWSER_WS_SIGNALING=true
RUN pnpm --filter @ponter/web build

# Install production-only dependencies for backend runtime
RUN pnpm install --prod --frozen-lockfile

###############################################################################
# Stage 3: runner — production all-in-one runtime
###############################################################################
FROM base AS runner

WORKDIR /app

# Install Nginx, Supervisord, and privilege-drop helper su-exec
RUN apk add --no-cache nginx supervisor su-exec

# Copy backend dependencies and compiled code
COPY --from=builder /app/package.json ./package.json
COPY --from=builder /app/pnpm-workspace.yaml ./pnpm-workspace.yaml
COPY --from=builder /app/node_modules ./node_modules
COPY --from=builder /app/packages ./packages
COPY --from=builder /app/apps/server/package.json ./apps/server/package.json
COPY --from=builder /app/apps/server/dist ./apps/server/dist

# Copy compiled frontend SPA to Nginx document root
COPY --from=builder /app/apps/web/dist /usr/share/nginx/html

# Copy Nginx, Supervisord, and Entrypoint configurations
COPY docker/nginx.web.conf /etc/nginx/http.d/default.conf
COPY docker/supervisord.conf /etc/supervisord.conf
COPY docker/entrypoint.sh /usr/local/bin/entrypoint.sh
RUN chmod +x /usr/local/bin/entrypoint.sh

# Ensure required run directories and data volume exist
RUN mkdir -p /app/data /run/nginx /var/log/supervisor && \
    chown -R node:node /app/data

VOLUME /app/data

# Default environment configuration
ENV DATABASE_PATH=/app/data/remote.db
ENV PORT=8787
ENV HOST=127.0.0.1
ENV PONTER_HTTP_PORT=80

EXPOSE 80

ENTRYPOINT ["/usr/local/bin/entrypoint.sh"]
CMD ["supervisord", "-c", "/etc/supervisord.conf"]
```
